# 🎓 Student Course Details

A responsive React application that displays a list of students and allows users to search students instantly by **name** or **attendance status** using a live search feature.

---

## 📖 About the Project

This project was built using **React.js** as part of my React learning journey. It demonstrates how to work with arrays of objects, React state, conditional rendering, and real-time searching.

Users can search students by typing their name or attendance status (Present/Absent). The application filters the results dynamically without reloading the page.

---

## ✨ Features

- 🔍 Live search functionality
- 👨‍🎓 Search students by **Name**
- ✅ Search students by **Attendance Status**
- ⚡ Instant filtering using `filter()` and `includes()`
- 🎯 Conditional rendering for "No Student Found"

## 🚀 How It Works

1. A list of student objects is stored in an array.
2. The user enters a search query.
3. React updates the search state using `useState`.
4. The application filters the students using:
   - `filter()`
   - `includes()`
5. Matching students are displayed instantly.
6. If no student matches the search query, a **"No Student Found"** message is displayed.
